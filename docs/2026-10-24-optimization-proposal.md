## 一、功能优化建议

### 1.1 P0 · 安全与稳定

| # | 问题 | 现状依据 | 建议 |
|---|---|---|---|
| 1 | **凭据明文存储** | `main/store.ts` 将 `password` / `privateKeyPath` / `passphrase` 直接写入 `connections.json` 明文 JSON | 改用 Electron `safeStorage` 加密后落盘（macOS 走 Keychain、Windows 走 DPAPI）；不可加密环境回退明文并在界面提示风险 |
| 2 | **无主机指纹校验** | `main/sshManager.ts` 的 `ConnectConfig` 未配置 `hostVerifier`，存在中间人风险 | 首次连接记录主机指纹（TOFU），之后连接时校验；指纹变化时弹窗警示（可对标 known_hosts 语义） |
| 3 | **断线后无重连入口** | `TerminalView.tsx` 断开后只打印「[连接已断开]」，状态置 `closed`，用户必须关标签再重开 | 终端内提供「重新连接」按钮；可选自动重连（指数退避，上限 3 次）。会话层已有连接池（`pools`），重建成本可控 |
| 4 | 渲染进程沙箱未开 | `main/index.ts` 中 `sandbox: false` | 评估开启 `sandbox: true`（preload 只用了 ipcRenderer 桥接，理论上兼容） |

### 1.2 P1 · 终端体验（与 Termius / FinalShell 的核心差距）

1. **终端内搜索**：接入 `@xterm/addon-search`，`Cmd+F` 呼出搜索条，高亮 + 上下跳转。
2. **字号与滚动缓冲**：当前写死 `fontSize: 13`（`TerminalView.tsx`）、scrollback 为 xterm 默认 1000 行。建议 `Cmd + /-`、`Ctrl+滚轮` 缩放；scrollback 可配置（含「无限」档）。
3. **链接识别**：`@xterm/plugin-web-links`，终端里 URL 可点击。
4. **右键粘贴 / 选中即复制**：SSH 客户端高频习惯，加设置项。
5. **rz/sz（ZMODEM）**：国内从 FinalShell/Xshell 迁移用户的强需求。主进程在 shell stream 上侦听 ZMODEM 起始序列转接 `zmodem.js`，配合现有 SFTP 进度 UI。
6. **分屏广播输入**：已有分屏（`splitLayout`），加上「同时输入到两个窗格」开关，批量运维场景价值大。
7. **快捷命令片段**：可配置的常用命令条（下拉/快捷键发送到当前会话）。
8. **会话日志**：终端输出可选落盘（按连接/日期存文件），排障场景刚需。
9. **标签页溢出与拖拽**：标签多时当前 flex 布局会挤压（`.term-tabs` 无滚动/换行处理）；补横向滚动 + 拖拽排序。
10. **超过 2 窗格的分屏**：当前 `SplitLayout` 只支持两窗格，可扩展为网格。

### 1.3 P1 · SFTP

1. **文件夹递归上传/下载（高优先）**：`main/sftpManager.ts` 用 `fastPut/fastGet`，只支持单文件；传目录会直接报错。需递归遍历 + 逐文件进度聚合。
2. **传输队列**：当前同时只显示一个进度（`SftpProgress` 单条），多文件串行覆盖显示。建议任务队列面板（多任务、总进度、失败重试）。
3. **排序与过滤**：文件列表现在固定「目录优先 + 名称排序」（`FilePanel.tsx` refresh 内）；加表头点击排序（名称/大小/时间）、当前目录过滤框、隐藏文件开关。
4. **权限/属性**：右键查看 chmod/属主，支持改权限（运维高频）。
5. **远程文件快捷编辑**：下载到临时目录 → 系统默认编辑器打开 → 监听保存回传，补齐「小改动不想开 vim」的场景。
6. **与终端联动**：「在终端中打开此目录」（向当前会话写入 `cd <path>\n`）与反向（面板跟随终端 cwd，可基于 OSC 7）。低成本高感知。
7. **面板宽度可拖拽**：`.file-panel` 写死 `width: 340px`。
8. **双栏模式（P2）**：本地浏览列 + 远程列，对拷拖传；可复用现有组件先做本地列表。

### 1.4 P2 · 连接管理

1. **导入 `~/.ssh/config`**：存量用户一键导入 Host/HostName/User/Port/IdentityFile，显著降低上手门槛（拉新利器）。
2. **导出/备份**：连接列表加密导出 JSON，方便换机。
3. **连接复制**：同类服务器只改 IP 的场景高频。
4. **侧栏主机条目可交互**：`Sidebar.tsx` 的 `.host-leaf` 目前是纯展示死 UI，不能点击。建议：单击筛选、双击直连，并显示连接状态点。
5. **列表搜索框**：连接多时按名称/地址模糊过滤。
6. **延迟结果持久化**：`HostTable.tsx` 的 `latency` 是组件内 state，切页即失；且只能一台台测。建议结果写回 store、表头加「全部测试」。
7. **跳板机 + 代理**：设计文档已就绪（`docs/superpowers/specs/2026-07-18-jumphost-proxy-design.md`），编辑弹窗占位 tab 已留，按 spec 落地即可。
8. **初始化脚本**：设计文档已就绪（`docs/superpowers/specs/2026-07-18-init-script-design.md`），同上。
9. **删除保护**：删除连接/分组目前用 `window.confirm`，建议应用内确认框；或输入名称确认（防误删）。

### 1.5 P2 · 系统信息

- `sysInfoCollector.ts` 目前只采「静态总量」：OS、核数、内存总量、根分区总量。建议补充 CPU/内存**实时使用率**（`/proc` 差值采样）、磁盘分区列表；采集时间人性化显示（「3 小时前」）；行摘要 hover 出详情卡。

### 1.6 P3 · 工程质量

1. `store.ts` 每次操作全量读写 JSON 文件（`load()` 无缓存）——连接多 + 界面频繁 `reload()` 时浪费。改内存缓存 + 防抖写盘 + 临时文件原子替换（防止写一半崩溃损坏）。
2. `connections.json` 无版本号/迁移机制，加字段时兼容旧文件。
3. 零测试：优先给 `sysInfoCollector` 的 4 个 parse 函数、`sftpManager.joinRemote`、`store` 补单测（纯函数，成本低）。
4. 无 CI：GitHub Actions 跑 `tsc -b` + 三平台打包产物（ssh2 原生依赖需注意 rebuild）。
5. **应用菜单与快捷键**：当前没有 `Menu.setApplicationMenu`，全应用零快捷键。基础集：`Cmd+N` 新建连接、`Cmd+T` 复制会话、`Cmd+W` 关标签、`Cmd+F` 终端搜索、`Cmd+1..9` 切标签、`Cmd+,` 设置。
6. i18n 脚手架（若考虑海外发行）。

## 三、应用图标重设计

### 3.1 现版问题诊断

当前 `build/icon.icns`：深色圆角方块 + 蓝紫渐变发光描边 + 终端窗框（红绿灯）+ 绿色 `>_`。

1. **三组色相打架**：蓝紫描边、绿提示符、红黄绿红绿灯同框，没有主色，小尺寸下糊成一团。
2. **描边光晕在 16–32px 下变成噪点**： macOS 菜单栏/Dock 小图上渐变描边细看像脏边。
3. **红绿灯占掉 1/4 高度**，挤压主体字形，且是「窗口」隐喻而非「SSH」隐喻。
4. 整体是常见模板样式，与界面的绿色主色（`--green: #34c759`）没有呼应。

### 3.2 设计原则

- 单一主字形（`>_`），16px 下可辨；
- 收敛到品牌绿单色系（与界面主题按钮同色）；
- 去掉红绿灯与多重渐变，保留 macOS squircle + 柔和光影。

### 3.3 四个候选方案

SVG 源文件在 `design/icon/`，可视化预览见对话中的图标方案页（含深浅底、16/32/64px 阶梯、Dock 场景模拟）。

| 方案 | 文件 | 构思 | 适用 |
|---|---|---|---|
| **A · 暗夜绿光（推荐）** | `concept-a-midnight.svg` | 深炭底 + 绿色渐变 `>_`，去掉一切多余元素 | 与应用内深色主题和绿色主色完全一致，最耐看、最小尺寸最清晰 |
| B · 终端连线 | `concept-b-link.svg` | 下划线延伸为链路、末端主机节点，表达「shell 连上服务器」 | SSH 语义最强、辨识度高；16px 下节点略挤 |
| C · 亮色极简 | `concept-c-light.svg` | 白底 + 深绿字形 | 用户 Dock 里深色图标多时最跳；深色桌面反差也够 |
| D · 青绿描边 | `concept-d-ring.svg` | 保留现版「描边圆环」轮廓记忆，蓝紫换青→绿，字形改白 | 品牌延续性最好，老用户无迁移感 |

**推荐 A**，理由：图标的第一职责是「在任意尺寸下被立刻认出」，A 是四案中最干净的；绿色与产品界面主色一致，形成「打开应用 = 看到同样的绿」的品牌闭环。B 可作为备选（如果更看重 SSH 语义表达）。

### 3.4 落地步骤

```bash
# 1. 由选中的 SVG 生成 1024px PNG（无损栅格化）
# 2. 生成 macOS iconset 并转 icns
mkdir icon.iconset
for s in 16 32 64 128 256 512; do
  sips -z $s $s icon_1024.png --out icon.iconset/icon_${s}x${s}.png
  sips -z $((s*2)) $((s*2)) icon_1024.png --out icon.iconset/icon_${s}x${s}@2x.png
done
iconutil -c icns icon.iconset -o build/icon.icns
# 3. Windows：导出带透明边距的圆角 PNG 覆盖 build/icon.png
# 4. 重新打包验证 Dock/任务栏/安装器三处显示
```
